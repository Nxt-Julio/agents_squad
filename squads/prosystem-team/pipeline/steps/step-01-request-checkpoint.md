# Step 01: Captura do Pedido

Se o usuário já descreveu a mudança na conversa, escreva a descrição aqui e pergunte só o que faltar (numa mensagem só). Se não, peça a descrição.

Inclua, quando possível:

1. Objetivo
2. Sistema/área afetada (ECV, PLACAS, GESTAOPRO, DISTRIBUIDORA, Consulta de Placas, portal/login, PRO360, site)
3. Comportamento esperado (como fica a tela, o que o sistema faz)
4. Restrições ou arquivos já conhecidos
5. Como o usuário vai validar

Grave no arquivo:

```
# Pedido

**Data:** {YYYY-MM-DD}
**Pedido:** {texto do usuário}
**Área:** {área}
**Comportamento esperado:** {...}
**Restrições:** {... ou "nenhuma"}
**Validação:** {...}
```
