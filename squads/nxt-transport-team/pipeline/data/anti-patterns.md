# Anti-Patterns

- Resumir o repositorio inteiro em vez de ler so os arquivos do escopo.
- Alterar arquivos de outro setor sem necessidade de contrato.
- Mudar payload/endpoint no backend sem atualizar Web e Mobile.
- Editar migration Prisma ja aplicada.
- Afirmar que teste/build passou sem ter executado o comando.
- Fazer commit, push, deploy ou publicar build sem pedido explicito do usuario.
