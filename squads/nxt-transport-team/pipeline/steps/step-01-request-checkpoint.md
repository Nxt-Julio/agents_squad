# Step 01: Request Intake

If the user already described the change in the conversation, write that description here and ask only for what is missing. Otherwise, ask the user to describe the change request.

Include, when possible:

1. Goal
2. Impacted repositories: Backend, Web, Mobile, or shared contract
3. Expected behavior
4. Constraints or files already known
5. Validation requirement
